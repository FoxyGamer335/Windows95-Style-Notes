# Windows 95 Style Notes

Интерактивное рабочее пространство для создания заметок в стиле Windows 95.

Каждая заметка представляет собой отдельное окно, которое можно перемещать, изменять в размере и редактировать. Рабочее пространство можно свободно перемещать и масштабировать, создавая что-то вроде виртуального рабочего стола.

## Возможности

* Окна заметок в стиле Windows 95
* Перемещение окон по бесконечному холсту
* Изменение размера окон
* Сетка для позиционирования окон
* Масштабирование рабочего пространства
* Поддержка жестов на сенсорных устройствах
* Редактирование содержимого заметок через встроенный редактор
* Поддержка HTML в содержимом заметок
* Возможность добавлять CSS и JavaScript к отдельным заметкам
* Автоматическое сохранение состояния
* Локальное хранение данных через IndexedDB
* Импорт и экспорт рабочего пространства в JSON
* Возможность удалять и переименовывать заметки
* Изменение порядка окон при взаимодействии с ними

## Редактор

Для редактирования содержимого используется [Ace Editor](https://ace.c9.io/).

Редактор поддерживает подсветку HTML, автодополнение, сниппеты и другие возможности Ace.

Содержимое заметки может быть обычным HTML:

```html
<h2>Заголовок</h2>
<p>Текст заметки</p>
```

Можно также использовать собственные стили:

```html
<style>
    p {
        font-size: 20px;
    }
</style>
```

и JavaScript:

```html
<script>
    console.log("Привет!");
</script>
```

Таким образом, отдельное окно может содержать не только текст, но и интерактивные элементы.

## Сохранение данных

Состояние рабочего пространства автоматически сохраняется в браузере с использованием **IndexedDB**.

Сохраняются:

* положение окон;
* размеры окон;
* порядок окон;
* названия заметок;
* содержимое заметок;
* положение камеры рабочего пространства;
* текущий масштаб.

Состояние сохраняется с небольшой задержкой после изменений, чтобы не выполнять запись в базу данных при каждом движении объекта.

## Импорт и экспорт

Рабочее пространство можно экспортировать в JSON-файл и восстановить его позднее.

В меню **«Настройки»** доступны:

* **Импортировать JSON**
* **Экспортировать JSON**

Экспорт создаёт файл `windows95-notes.json`.

Это позволяет, например, переносить набор заметок между браузерами или делать резервные копии.

## Управление

### Рабочее пространство

* **ЛКМ / касание по пустому месту** — перемещение рабочего пространства
* **Перетаскивание окна за заголовок** — перемещение окна
* **Хватание за правый нижний край** — изменение размера окна
* **Взаимодействие с окном** — переносит его на передний план
* **Два пальца на сенсорном экране / Кручение колеса мыши** — масштабирование рабочего пространства

Позиция окон привязана к сетке.

## Создание заметки

Нажмите кнопку **«Создать окно»**.

Новое окно появится в центре текущего рабочего пространства и автоматически откроется в режиме редактирования.

В редакторе можно изменить:

* название окна;
* содержимое;
* HTML;
* CSS;
* JavaScript.

После подтверждения содержимое отображается непосредственно внутри окна.

## Структура данных

Рабочее пространство хранится примерно в следующем виде:

```json
{
    "camera": {
        "x": 0,
        "y": 0,
        "scale": 1
    },
    "windows": {
        "window_id": {
            "x": 0,
            "y": 0,
            "width": 350,
            "height": 350,
            "zIndex": 0,
            "title": "Название",
            "content": "<p>Содержимое</p>"
        }
    }
}
```

## Запуск

Проект является клиентским веб-приложением и не требует отдельного backend-сервера.

Для запуска достаточно открыть `index.html` в браузере или разместить проект на любом статическом хостинге.

Например, проект можно разместить через **GitHub Pages**.

[Демонстрация](https://foxygamer335.github.io/Windows95-Style-Notes/)
## Используемые технологии

* HTML
* CSS
* JavaScript
* IndexedDB
* Ace Editor
* Bootstrap Icons

Ace Editor и Bootstrap Icons подключаются непосредственно в `index.html`.

## Данные

Все заметки хранятся локально в браузере пользователя.

Проект не требует собственной базы данных или серверной части для хранения рабочего пространства.

> **Важно:** очистка данных сайта браузером может привести к потере локально сохранённых заметок. Для резервного копирования используйте экспорт JSON.
